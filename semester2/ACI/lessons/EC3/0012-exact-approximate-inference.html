1. The Inference Goal

A Bayesian Network (BN) is a compact representation of a joint probability distribution. But what we usually want is not the full joint — we want answers to specific questions: "Given that I see evidence \(e\), what is the probability of query \(Q\)?"

\[ P(Q \mid e) = \frac{P(Q, e)}{P(e)} = \alpha \cdot P(Q, e) \]

The constant \(\alpha = 1/P(e)\) is a normalising factor. We compute \(P(Q, e)\) by summing over all hidden (unobserved) variables \(H\):

\[ P(Q \mid e) = \alpha \sum_{h} P(Q, e, h) \]
Key Terms

Query variable \(Q\): what we want to know.
Evidence \(e\): observed facts (fixed in our computation).
Hidden variables \(H\): unobserved — we sum them out.

Analogy

Think of a Bayesian Network as a city map. Inference is asking "given that there's a traffic jam on Main St (evidence), what's the probability it will rain tonight (query)?" The hidden variables are all the intermediate causes you can't see directly.

There are two main strategies: Exact Inference gives the precisely correct answer; Approximate Inference gives a good-enough answer much faster for large networks.

2. Exact Inference by Enumeration

The simplest exact method: enumerate every possible assignment of all hidden variables, compute the joint probability of each, and sum up the ones consistent with the query and evidence.

Algorithm

  1. For each value \(q\) of the query variable: for each combination of hidden variable values \(h\):
    • Compute the joint \(P(q, e, h) = \prod_i P(X_i \mid \text{parents}(X_i))\)
  2. Sum: \(P(Q=q, e) = \sum_h P(q, e, h)\)
  3. Normalise: \(P(Q \mid e) = \alpha \langle P(Q=T, e),\ P(Q=F, e)\rangle\)
Exam Tip

Complexity is \(O(2^n)\) for \(n\) binary variables — exponential. In the exam, networks have 3–4 variables so enumeration is always feasible. Show every row of your enumeration table for full marks.

3. Worked Example: Enumeration (Sample Paper Q4)

Problem Setup (from Sample Paper)

Atul (A) attends class with \(P(A=T)=0.8\). Kavya (K) attends with \(P(K=T)=0.6\). They are independent. Sruthi (S) joins if and only if at least one of Atul or Kavya joins:

  • \(P(S=T \mid A=T, K=T) = 1\)
  • \(P(S=T \mid A=T, K=F) = 1\)
  • \(P(S=T \mid A=F, K=T) = 1\)
  • \(P(S=T \mid A=F, K=F) = 0\)

Query: \(P(A=T \mid S=T,\ K=T)\)

Step-by-Step Enumeration

Evidence: \(S=T,\ K=T\). Query: \(A\). Hidden: none — \(K\) is evidence, \(S\) is evidence, \(A\) is the query. We enumerate \(A \in \{T, F\}.\)

For \(A=T\):

\[P(A{=}T,\ K{=}T,\ S{=}T) = P(A{=}T)\cdot P(K{=}T)\cdot P(S{=}T\mid A{=}T,K{=}T)\] \[= 0.8 \times 0.6 \times 1 = \mathbf{0.480}\]

For \(A=F\):

\[P(A{=}F,\ K{=}T,\ S{=}T) = P(A{=}F)\cdot P(K{=}T)\cdot P(S{=}T\mid A{=}F,K{=}T)\] \[= 0.2 \times 0.6 \times 1 = \mathbf{0.120}\]

Normalise:

\[\alpha = \frac{1}{0.480 + 0.120} = \frac{1}{0.600} \approx 1.667\] \[P(A{=}T \mid S{=}T, K{=}T) = 1.667 \times 0.480 = \boxed{0.800}\]
Result

Given that Sruthi is present and Kavya is present, the probability that Atul came is still 0.8 — because Sruthi's attendance is fully explained by Kavya alone (explaining away makes Atul conditionally independent of \(S\) given \(K=T\)).

Additional: P(A=T | S=T) — Sruthi present, Kavya unobserved

Now K is also hidden. Enumerate all four combinations:

AKP(A)·P(K)·P(S=T|A,K)Value
TT0.8 × 0.6 × 10.480
TF0.8 × 0.4 × 10.320
FT0.2 × 0.6 × 10.120
FF0.2 × 0.4 × 00.000

Sum for \(A=T\): \(0.480 + 0.320 = 0.800\). Sum for \(A=F\): \(0.120 + 0.000 = 0.120\).

\[P(A{=}T \mid S{=}T) = \frac{0.800}{0.800+0.120} = \frac{0.800}{0.920} \approx \boxed{0.870}\]

4. Variable Elimination (VE)

Enumeration recomputes many intermediate products. Variable Elimination (VE) is smarter: it eliminates one hidden variable at a time by summing it out early, caching the result as a factor, and reusing it.

What is a Factor?

A factor is a table of probability values for a subset of variables. Each CPT in a BN is initially a factor. VE combines and marginalises factors one step at a time.

VE Algorithm

  1. Start with all CPTs as factors.
  2. For each hidden variable \(H_i\) (in some order):
    • Collect all factors mentioning \(H_i\).
    • Multiply them into one big factor \(f_{\text{new}}\).
    • Sum out \(H_i\): \(f_{\text{new}}' = \sum_{H_i} f_{\text{new}}\). Replace the collected factors with \(f_{\text{new}}'\).
  3. Multiply all remaining factors and normalise.
Exam Tip — Professor's Emphasis

The professor said in class: "Variable elimination — very important." Expect a question where you must eliminate one or two variables step by step and show the intermediate factor tables.

5. Worked Example: Variable Elimination

Using the same Atul/Kavya/Sruthi network. Compute \(P(S=T)\) using VE to eliminate \(A\) then \(K\).

Initial factors: \(f_1(A)\), \(f_2(K)\), \(f_3(S,A,K)\).

Step 1: Eliminate A

Factors involving \(A\): \(f_1(A)\) and \(f_3(S,A,K)\). Multiply:

SAK\(f_1(A)\cdot f_3(S,A,K)\)
TTT0.8 × 1 = 0.800
TTF0.8 × 1 = 0.800
TFT0.2 × 1 = 0.200
TFF0.2 × 0 = 0.000
FTT0.8 × 0 = 0.000
FTF0.8 × 0 = 0.000
FFT0.2 × 0 = 0.000
FFF0.2 × 1 = 0.200

Sum out \(A\) to get new factor \(f_4(S,K)\):

\[f_4(S{=}T,K{=}T) = 0.800+0.200 = 1.000\] \[f_4(S{=}T,K{=}F) = 0.800+0.000 = 0.800\] \[f_4(S{=}F,K{=}T) = 0.000+0.000 = 0.000\] \[f_4(S{=}F,K{=}F) = 0.000+0.200 = 0.200\]

Step 2: Eliminate K

Multiply \(f_4(S,K)\) with \(f_2(K)\), then sum out \(K\):

\[f_5(S{=}T) = f_4(T,T)\cdot f_2(T) + f_4(T,F)\cdot f_2(F) = 1.0\times0.6 + 0.8\times0.4 = 0.6+0.32 = 0.920\] \[f_5(S{=}F) = f_4(F,T)\cdot f_2(T) + f_4(F,F)\cdot f_2(F) = 0.0\times0.6 + 0.2\times0.4 = 0.080\]
Result

\(P(S=T) = 0.920\), \(P(S=F) = 0.080\). This matches what enumeration gives: \(0.480+0.320+0.120+0.000 = 0.920\). ✓

6. Approximate Inference — Gibbs Sampling

When the network is too large for exact methods, we use Gibbs Sampling — a Markov Chain Monte Carlo method that generates samples from the joint distribution and estimates probabilities by counting.

Markov Blanket

The Markov blanket of variable \(X\) is: \(X\)'s parents + \(X\)'s children + \(X\)'s co-parents (other parents of \(X\)'s children). Given the Markov blanket, \(X\) is conditionally independent of everything else.

Algorithm

  1. Initialise: assign random values to all non-evidence variables.
  2. Repeat for many iterations:
    • Pick a non-evidence variable \(X_i\) (round-robin or random).
    • Sample a new value for \(X_i\) from \(P(X_i \mid \text{Markov blanket of } X_i)\).
    • Record the current state of the query variable.
  3. Discard the first \(B\) samples (burn-in period — chain hasn't converged).
  4. Estimate: \(P(Q=q \mid e) \approx \frac{\text{# samples where }Q=q}{\text{total samples after burn-in}}\).
Exam Tip — Professor's Direct Statement

"Only one kind of sampling will be asked" — that's Gibbs sampling. Know the steps, what Markov blanket means, and what burn-in is. You won't need to implement Likelihood Weighting.

Analogy

Gibbs sampling is like adjusting one dish at a time in a potluck dinner: fix everyone else's food, decide what the current cook should bring to best complement the rest. Repeat around the table. Over many rounds, the combination converges to everyone's true preferences.

Why It Works

The sequence of states forms a Markov chain. Under mild conditions, this chain's stationary distribution equals the true joint \(P(X_1,\ldots,X_n)\). So long-run sample frequencies converge to true probabilities.

7. When to Use Which Method

MethodComplexityAnswerBest For
Enumeration\(O(2^n)\) — exponentialExactSmall nets (3–5 nodes); exam questions
Variable Elimination\(O(2^w)\) where \(w\) = treewidthExactMedium nets; structured queries; exam questions
Gibbs Sampling\(O(\text{iterations})\) — linearApproximateLarge real-world nets; approximate answer OK

In the exam: use enumeration for networks with ≤ 2 hidden variables (fastest to show). Use VE when asked to "eliminate" a variable. Describe Gibbs when asked about approximate inference.

9. Self-Check Exercises

Exercise 1: Enumeration — Compute P(A=T | C=T)

Given: BN with \(A \to C \leftarrow B\). \(P(A=T)=0.6\), \(P(B=T)=0.4\).

CPT for C: \(P(C{=}T|A{=}T,B{=}T)=0.9\), \(P(C{=}T|A{=}T,B{=}F)=0.5\), \(P(C{=}T|A{=}F,B{=}T)=0.7\), \(P(C{=}T|A{=}F,B{=}F)=0.1\).

Compute \(P(A=T \mid C=T)\) by enumeration.

Solution: Enumerate B (hidden):

  • \(A=T, B=T\): \(0.6\times0.4\times0.9 = 0.216\)
  • \(A=T, B=F\): \(0.6\times0.6\times0.5 = 0.180\)

Sum for \(A=T\): \(0.216+0.180 = 0.396\)

  • \(A=F, B=T\): \(0.4\times0.4\times0.7 = 0.112\)
  • \(A=F, B=F\): \(0.4\times0.6\times0.1 = 0.024\)

Sum for \(A=F\): \(0.112+0.024 = 0.136\)

Normalise: \(\alpha = 1/(0.396+0.136) = 1/0.532\)

\(\boxed{P(A=T \mid C=T) = 0.396/0.532 \approx 0.744}\)

Exercise 2: Markov Blanket — What is the MB of C in the above network?

Network: \(A \to C \leftarrow B\).

Markov Blanket of C = parents of C + children of C + co-parents of C's children.

  • Parents of C: {A, B}
  • Children of C: none (C is a leaf)
  • Co-parents of C's children: none

\(\boxed{MB(C) = \{A, B\}}\)

This means: given A and B, C is independent of everything else in the network.

Exercise 3: Explain the key difference between exact and approximate inference.

Exact inference (enumeration, variable elimination) computes the true probability \(P(Q|e)\) precisely. It is complete and correct but computationally expensive — exponential in the worst case (\(O(2^n)\)).

Approximate inference (Gibbs sampling) estimates the probability by generating random samples. It scales to large networks but the answer has statistical error. As the number of samples grows, the estimate converges to the true value.

Rule of thumb: in the exam, use exact inference. In real AI systems with 100+ variables, use approximate.
