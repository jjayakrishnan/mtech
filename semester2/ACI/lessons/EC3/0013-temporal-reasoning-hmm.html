1. Why Static Models Aren't Enough

A Bayesian Network captures a snapshot of the world. But many real problems involve the world changing over time. Yesterday's weather affects today's. A patient's health evolves. A robot's position changes step by step.

We need models that reason over sequences: \(X_1, X_2, \ldots, X_T\).

Markov Assumption (1st order)

The current state depends only on the immediately previous state: \[ P(X_t \mid X_0, X_1, \ldots, X_{t-1}) = P(X_t \mid X_{t-1}) \] This makes the maths tractable. Real processes are often approximately Markov.

Stationary Transitions

The transition distribution \(P(X_t \mid X_{t-1})\) is the same for all time steps. This means we learn one set of transition probabilities and reuse it at every step.

Analogy

Imagine a security guard in an underground bunker. They can't see outside (hidden state = Rain or No Rain), but they can observe whether people bring umbrellas (observation). The guard must track the probable weather over time using only what they see.

2. Hidden Markov Model (HMM) — Components

An HMM has two layers: a hidden state sequence that evolves over time, and observable evidence at each step.

ComponentNotationExample (Rain/Umbrella)
Hidden states\(X_t\)Rain=T or Rain=F at time \(t\)
Observations\(E_t\)Umbrella=T or Umbrella=F at time \(t\)
Initial distribution\(P(X_0)\)\(P(R_0{=}T)=0.5\)
Transition model\(P(X_t \mid X_{t-1})\)\(P(R_t{=}T|R_{t-1}{=}T)=0.7\)
Sensor/Emission model\(P(E_t \mid X_t)\)\(P(U_t{=}T|R_t{=}T)=0.9\)

The key property: given \(X_t\), the observation \(E_t\) is independent of everything else. This is the sensor Markov property.

3. Filtering — Tracking the Current State

Filtering answers: "Given all observations up to now, what is the probability of the current hidden state?" \[ P(X_t \mid e_{1:t}) = ? \]

The forward algorithm computes this recursively:

\[ P(X_t \mid e_{1:t}) = \alpha \cdot P(e_t \mid X_t) \cdot \underbrace{\sum_{x_{t-1}} P(X_t \mid x_{t-1}) \cdot P(x_{t-1} \mid e_{1:t-1})}_{\text{prediction from previous step}} \]

Read it right-to-left:

  1. Predict: take last step's belief, multiply by transition, sum over old states.
  2. Update: multiply by the emission probability for the new observation.
  3. Normalise: multiply by \(\alpha = 1/P(e_t \mid e_{1:t-1})\).
Exam Tip

Show your work in two sub-steps: (i) the prediction (un-normalised), (ii) the update and normalisation. The professor's Rain/Umbrella example is the canonical exam question — work through it numerically.

4. Worked Example: Rain/Umbrella HMM (Sample Paper Q2B)

Given (from the exam question)
  • States: \(R_t \in \{T, F\}\) (Rain or no Rain)
  • Observations: \(U_t \in \{T, F\}\) (Umbrella seen)
  • Prior: \(P(R_0{=}T) = 0.5\), \(P(R_0{=}F) = 0.5\)
  • Transition: \(P(R_t{=}T|R_{t-1}{=}T)=0.7\), \(P(R_t{=}T|R_{t-1}{=}F)=0.3\)
  • Emission: \(P(U_t{=}T|R_t{=}T)=0.9\), \(P(U_t{=}T|R_t{=}F)=0.2\)

Part (a): P(R₃ | U₁ = True)

Only one observation \(U_1=T\). We compute \(P(R_1|U_1=T)\) then predict forward.

Step 1 — Compute P(R₁ | U₁=T):

\[\text{Predict: } P(R_1{=}T) = 0.7\times0.5 + 0.3\times0.5 = 0.35+0.15 = 0.50\] \[P(R_1{=}F) = 0.3\times0.5 + 0.7\times0.5 = 0.15+0.35 = 0.50\] \[\text{Update: } f_T = 0.9\times0.50 = 0.45, \quad f_F = 0.2\times0.50 = 0.10\] \[\alpha = 1/0.55 \Rightarrow P(R_1{=}T|U_1{=}T) \approx 0.818, \quad P(R_1{=}F|U_1{=}T) \approx 0.182\]

Step 2 — Predict P(R₂ | U₁=T) (no new observation):

\[P(R_2{=}T|U_1) = 0.7\times0.818 + 0.3\times0.182 = 0.573 + 0.055 = 0.628\] \[P(R_2{=}F|U_1) = 0.3\times0.818 + 0.7\times0.182 = 0.245 + 0.127 = 0.372\]

Step 3 — Predict P(R₃ | U₁=T):

\[P(R_3{=}T|U_1) = 0.7\times0.628 + 0.3\times0.372 = 0.440 + 0.112 = \mathbf{0.552}\] \[P(R_3{=}F|U_1) = 0.3\times0.628 + 0.7\times0.372 = 0.188 + 0.260 = \mathbf{0.448}\]
Answer: P(R₃ | U₁=T) ≈ [0.552, 0.448]

Notice the distribution is moving toward the stationary distribution of the Markov chain as \(k\) grows.

Part (b): How accurate when k >> 1?

Key Insight — Stationary Distribution

As \(k \to \infty\), \(P(R_k \mid U_1=T)\) converges to the stationary distribution of the transition matrix — regardless of the initial evidence. The influence of the single early observation fades. The stationary distribution satisfies \(\pi = \pi \cdot T\).

For this chain: \(\pi(R{=}T) = 0.3/(0.3+0.3) = 0.5\). So for large \(k\), \(P(R_k|U_1=T) \approx [0.5, 0.5]\). The evidence "wears off".

Part (c): P(R₂ | U₁=F, U₂=F, U₃=T)

Step 1 — P(R₁ | U₁=F):

\[f_T = P(U_1{=}F|R_1{=}T)\times P(R_1{=}T) = 0.1\times0.5 = 0.050\] \[f_F = P(U_1{=}F|R_1{=}F)\times P(R_1{=}F) = 0.8\times0.5 = 0.400\] \[\alpha=1/0.45 \Rightarrow P(R_1{=}T|U_1{=}F)\approx 0.111,\quad P(R_1{=}F|U_1{=}F)\approx 0.889\]

Step 2 — Predict & Update for U₂=F:

\[\text{pred}_T = 0.7\times0.111+0.3\times0.889=0.078+0.267=0.344\] \[\text{pred}_F = 0.3\times0.111+0.7\times0.889=0.033+0.622=0.656\] \[f_T=0.1\times0.344=0.034,\quad f_F=0.8\times0.656=0.525\] \[\alpha=1/0.559 \Rightarrow P(R_2{=}T|U_1{=}F,U_2{=}F)\approx 0.062,\quad P(R_2{=}F)\approx 0.938\]
Exam Tip

The question asks for \(P(R_2 \mid U_1=F, U_2=F, U_3=T)\). Notice \(U_3=T\) is a future observation — it's smoothing, not filtering. In many exam versions, you only need to compute up to the asked time step using the forward pass. Check if the question asks for filtering or smoothing.

5. Viterbi — Most Probable State Sequence

Filtering gives the probability distribution over the current state. But sometimes we want the single most likely sequence of states: \[ \arg\max_{x_{1:T}} P(x_{1:T} \mid e_{1:T}) \]

Viterbi is a dynamic programming algorithm that solves this efficiently. It's identical in structure to the forward algorithm except we use max instead of sum:

\[ m_t(x_t) = P(e_t \mid x_t) \cdot \max_{x_{t-1}} \left[P(x_t \mid x_{t-1}) \cdot m_{t-1}(x_{t-1})\right] \]

At each step, record a backpointer \(bp_t(x_t) = \arg\max_{x_{t-1}}[\cdots]\). After reaching the end, trace back the pointers to recover the best sequence.

Viterbi on Rain/Umbrella (U₁=T, U₂=T)

Initialise t=1 (U₁=T):

\[m_1(T) = P(U_1{=}T|R_1{=}T)\cdot P(R_1{=}T) = 0.9\times0.5 = 0.450 \quad bp_1(T)=\text{start}\] \[m_1(F) = 0.2\times0.5 = 0.100 \quad bp_1(F)=\text{start}\]

Propagate t=2 (U₂=T):

\[m_2(T): \max[m_1(T)\cdot P(T|T),\ m_1(F)\cdot P(T|F)]\times P(U_2{=}T|R_2{=}T)\] \[= \max[0.450\times0.7,\ 0.100\times0.3]\times0.9 = \max[0.315, 0.030]\times0.9 = 0.315\times0.9 = \mathbf{0.2835},\quad bp_2(T)=T\] \[m_2(F): \max[0.450\times0.3,\ 0.100\times0.7]\times0.2 = \max[0.135,0.070]\times0.2 = 0.135\times0.2 = \mathbf{0.027},\quad bp_2(F)=T\]

Best sequence: Best at \(t=2\) is \(R_2=T\). Traceback: \(bp_2(T)=T\) → \(R_1=T\). Sequence: \(\boxed{T \to T}\).

Filtering vs Viterbi

Filtering asks: "What is the marginal distribution over today's state?" Uses sum.
Viterbi asks: "What is the single best sequence of states?" Uses max + backpointers.

7. Markov Decision Process (MDP)

In HMMs the agent observes but does not act. An MDP adds actions: the agent chooses what to do, and different actions lead to different transitions and rewards.

MDP Components
  • States \(S\): all possible world states
  • Actions \(A\): what the agent can do
  • Transition \(P(s' \mid s, a)\): stochastic outcome of action \(a\) in state \(s\)
  • Reward \(R(s, a)\): immediate payoff for being in state \(s\) and taking action \(a\)
  • Discount factor \(\gamma \in [0,1)\): how much future rewards are valued

Optimal Value Function and Policy

\[ V^*(s) = \max_a \left[ R(s,a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^*(s') \right] \]
\[ \pi^*(s) = \arg\max_a \left[ R(s,a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^*(s') \right] \]

The Discount Factor γ (Sample Paper Q1d)

Significance of the Discount Factor
  • \(\gamma = 0\): Fully myopic — agent only cares about immediate reward. Ignores all future consequences. Very short-sighted.
  • \(\gamma \to 1\): Far-sighted — agent weighs distant rewards almost equally to immediate ones. Plans ahead.
  • Practical range: \(0.9\)–\(0.99\) for most RL problems.

Example: A medical AI with \(\gamma = 0\) might prescribe aggressive treatment for quick symptom relief, ignoring long-term side effects. With \(\gamma \approx 0.95\), it plans treatments that optimise long-term patient health.

Exam Tip — Q1d Style

When asked to explain the discount factor "with a plagiarism-free example/scenario," use a concrete domain (healthcare, autonomous driving, education) and describe how γ changes the agent's behaviour. Show the Bellman equation and explain what happens as γ→0 vs γ→1.

Worked MDP Example — 2-State System

Setup

States: \(s_1\) (Good), \(s_2\) (Bad). One action: "Work". Rewards: \(R(s_1)=+10\), \(R(s_2)=-5\). Transitions: \(P(s_1|s_1)=0.8\), \(P(s_2|s_1)=0.2\), \(P(s_1|s_2)=0.5\), \(P(s_2|s_2)=0.5\). \(\gamma=0.9\). Initialise \(V_0(s_1)=V_0(s_2)=0\).

Iteration 1:

\[V_1(s_1) = 10 + 0.9(0.8\times0 + 0.2\times0) = \mathbf{10}\] \[V_1(s_2) = -5 + 0.9(0.5\times0 + 0.5\times0) = \mathbf{-5}\]

Iteration 2:

\[V_2(s_1) = 10 + 0.9(0.8\times10 + 0.2\times(-5)) = 10 + 0.9(8-1) = 10+6.3 = \mathbf{16.3}\] \[V_2(s_2) = -5 + 0.9(0.5\times10 + 0.5\times(-5)) = -5 + 0.9(5-2.5) = -5+2.25 = \mathbf{-2.75}\]

The values converge to \(V^*(s_1) = 46.15\) and \(V^*(s_2) = 32.31\) after many iterations.

Exercise 1: Compute P(R₁=T | U₁=True) from scratch.

Using prior \(P(R_0=T)=P(R_0=F)=0.5\), transition as above:

Predict: \(P(R_1{=}T) = 0.7\times0.5 + 0.3\times0.5 = 0.500\)

Exercise 2: What does the Markov assumption mean? Why is it useful?

The Markov assumption states that the current state \(X_t\) is conditionally independent of all past states \(X_0,\ldots,X_{t-2}\) given the immediately previous state \(X_{t-1}\).

Why useful: Without it, we'd need to track the entire history to make predictions — computationally infeasible. With it, the forward algorithm only needs to maintain a belief distribution over current states (finite size), making exact inference tractable.

Exercise 3: Difference between filtering and smoothing.

Filtering: \(P(X_t \mid e_{1:t})\) — uses only past and current evidence. Online (real-time) — you get the answer as new evidence arrives.

Smoothing: \(P(X_k \mid e_{1:T})\) for \(k < T\) — uses all evidence including future observations. More accurate because it uses evidence on both sides of the unknown state. Requires waiting until all evidence is collected (or using the backward pass).

Example: In speech recognition, smoothing improves phoneme recognition by using future phonemes to resolve ambiguity.
