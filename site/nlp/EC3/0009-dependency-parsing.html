1 · Motivation: Why Dependency Parsing?

Analogy

"I saw a girl with a telescope." — Phrase-structure parsing gives you a constituency tree. Dependency parsing cuts to the chase: it directly says who modifies whom. The arrow from "telescope" to "saw" (or "girl") immediately resolves the ambiguity.

Dependency parsing focuses on binary asymmetric relations (dependencies) between words — rather than grouping words into nested phrases. This makes it more direct for many downstream tasks (information extraction, relation detection, MT reordering).

ApproachRepresentsStrength
Phrase-structure (CFG)Nested constituents (NP, VP…)Explicit phrase grouping, good for generation
Dependency parsingHead–dependent word pairsDirect word–word relations, language-independent

2 · Dependency Structure

Definition

A dependency structure is a directed graph where:

  • Nodes are the words in the sentence (plus a virtual ROOT node)
  • Directed arcs go from head → dependent
  • Each arc is labelled with a grammatical relation (nsubj, obj, det, prep…)
  • The structure is a projective tree: connected, acyclic, each word has exactly one head

Example: "Bills were submitted by Brownback"

ROOT ──nsubjpass──► submitted submitted ──auxpass──► were submitted ──prep──► by by ──pobj──► Brownback submitted ──nsubjpass──► Bills

Reading: "submitted" is the root; "Bills" is the passive subject; "Brownback" is the object of preposition "by".

Formal Properties
  • Connected: every word reachable from ROOT
  • Acyclic: no word is its own ancestor
  • Single-head: each word has exactly one incoming arc (except ROOT)
  • Projective: arcs don't cross when drawn above the sentence (for many languages)

5 · Arc-Eager Algorithm (MaltParser)

State Configuration

At each step, the parser holds:

  • Stack \(\sigma\): words being processed (starts with ROOT)
  • Buffer \(\beta\): unprocessed input words
  • Arc set \(A\): dependency arcs built so far

Four Transition Operations

OperationWhen to useEffect
SHIFTbuffer[0] depends on something to its rightMove buffer[0] onto top of stack
LEFT-ARC(r)stack-top is dependent of buffer-frontAdd arc buffer[0]→stack-top with label r; pop stack
RIGHT-ARC(r)buffer-front is dependent of stack-topAdd arc stack-top→buffer[0] with label r; push buffer[0]
REDUCEstack-top has its head and all dependentsPop stack (finished with this word)

Worked Example: "I saw a girl"

Step-by-Step Trace
StepStackBufferActionArc Added
0[ROOT][I, saw, a, girl]SHIFT—
1[ROOT, I][saw, a, girl]LEFT-ARC(nsubj)saw→I
2[ROOT][saw, a, girl]SHIFT—
3[ROOT, saw][a, girl]SHIFT—
4[ROOT, saw, a][girl]LEFT-ARC(det)girl→a
5[ROOT, saw][girl]RIGHT-ARC(obj)saw→girl
6[ROOT, saw, girl][]REDUCE—
7[ROOT, saw][]RIGHT-ARC(root)ROOT→saw

Learning the Classifier

A machine learning classifier (SVM, neural net) maps the current configuration to the best action. Features include:

  • Word and POS tag of stack-top and buffer-front
  • Partial arc labels already assigned
  • Children of stack-top and buffer-front

Training uses an oracle — at each state, the oracle provides the correct action from the gold-standard parse. The classifier learns from these (state, action) pairs.

Exam Trap

Arc-Eager is greedy — it makes irreversible decisions at each step. This gives \(O(n)\) parsing but can propagate errors. Arc-Standard is an alternative transition system where RIGHT-ARC doesn't push; both are examinable.

6 · Graph-Based Parsing (Chu-Liu-Edmonds)

Graph-based parsers score all possible arcs between words, then find the Maximum Spanning Tree (MST) — the tree with highest total arc score.

  1. Score every possible arc \((i \to j, r)\) using a model (e.g., biaffine scorer)
  2. Build a complete weighted directed graph with these scores
  3. Run Chu-Liu-Edmonds algorithm to find the MST
Chu-Liu-Edmonds Algorithm
  1. For each node, greedily select the highest-scoring incoming arc
  2. If no cycle → done (the selected arcs form the MST)
  3. If a cycle exists → contract the cycle into a single node, adjusting scores
  4. Recurse on the contracted graph, then expand back

Complexity: \(O(n^2)\) for scoring + \(O(n^2)\) for MST = overall \(O(n^2)\)

$$\text{MST} = \arg\max_{T \in \mathcal{T}} \sum_{(h,d) \in T} \text{score}(h, d)$$

7 · Evaluation Metrics

MetricWhat it checksFormula
UAS — Unlabelled Attachment ScoreArc direction only (head–dependent pair correct)\(\frac{\text{correct arcs}}{\text{total arcs}}\)
LAS — Labelled Attachment ScoreArc + label both correct\(\frac{\text{correct (arc, label) pairs}}{\text{total arcs}}\)
Exam Note

LAS ≤ UAS always. If a parser gets the head right but labels it with the wrong relation type, it gains UAS but not LAS. State-of-the-art systems on Penn Treebank: UAS ~95%, LAS ~93%.

9 · Practice Questions

Q1 · What is UAS and how does it differ from LAS?

UAS (Unlabelled Attachment Score) = % of words where the correct head is predicted, ignoring the relation label. LAS (Labelled Attachment Score) = % of words where both the head AND the relation label are correct. LAS ≤ UAS. LAS is the stricter, standard evaluation metric for dependency parsing.

Q2 · List the four Arc-Eager transitions and when each is used.

SHIFT: Push buffer front onto stack — use when buffer[0] needs more words to its right before its head can be determined.
LEFT-ARC(r): buffer[0] is head of stack-top — pop stack and add arc.
RIGHT-ARC(r): stack-top is head of buffer[0] — add arc, shift buffer[0] to stack.
REDUCE: stack-top has found its head and all its dependents — pop stack.

Q3 · Why does Chu-Liu-Edmonds handle cycles?

The greedy arc selection in MST algorithms may form cycles (word A's best head is B, but B's best head is A). Chu-Liu-Edmonds detects any such cycle, contracts it into a single super-node, re-scores incoming/outgoing arcs relative to the cycle, and recurses. When it unwinds, it recovers the cycle-free MST. This gives correct, globally optimal results in \(O(n^2)\).

Q4 (6-mark) · Compare transition-based and graph-based dependency parsing.

Transition-based (Arc-Eager): \(O(n)\) parsing; greedy left-to-right; trains a local classifier on (state→action); fast, suitable for real-time; but error propagation — early mistakes affect later decisions.
Graph-based (MST): \(O(n^2)\) scoring + Chu-Liu-Edmonds for MST; globally optimal given the arc scoring model; better for long-range dependencies; slower.
In practice: Neural transition parsers (e.g., Chen & Manning 2014) close the accuracy gap while keeping speed. Graph-based models with biaffine attention (Dozat & Manning 2017) achieve SOTA accuracy. Choice depends on speed vs accuracy trade-off.
