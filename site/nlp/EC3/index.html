Quick Reference

Key formulas to memorize
  • PCFG: \(P(T) = \prod P(r_i)\)
  • CKY: \(O(n^3)\)
  • RNN: \(h_t = \tanh(W_h h_{t-1} + W_x x_t)\)
  • Attention: \(\text{softmax}(QK^T/\sqrt{d_k})V\)
  • ROUGE-N: recall over n-grams
  • MMR: \(\lambda \text{Sim}(d,q) - (1-\lambda)\max_S \text{Sim}(d,S)\)
  • RAG budget: \(\lfloor\text{avail}/\text{chunk}\rfloor\)
Common exam traps
  • CKY needs CNF — always convert first
  • LAS ≤ UAS always
  • MFS baseline ~65% — beat it or fail
  • Token budget: use ⌊floor⌋ not ceiling
  • Lead baseline beats many summarizers on news
