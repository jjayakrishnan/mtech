1. Probability Foundations

Logic assumes the world is either true or false. The real world is uncertain. Probability gives agents a principled way to reason with incomplete information — "I'm 80% sure the room ahead is safe."

Core Probability Rules

RuleFormulaMeaning
Non-negativity\( P(A) \geq 0 \)Probabilities are never negative
Normalisation\( \sum_a P(A{=}a) = 1 \)All outcomes sum to 1
Product (Chain) Rule\( P(A,B) = P(A|B)\cdot P(B) \)Joint = conditional × marginal
Conditional Probability\( P(A|B) = \dfrac{P(A,B)}{P(B)} \)Probability of A given B is known
Marginalisation\( P(A) = \sum_b P(A,B{=}b) \)Sum over all values of B

Worked Example — Conditional Probability

P(Cavity) = 0.10, P(Toothache | Cavity) = 0.70, P(Toothache | ¬Cavity) = 0.10.

What is P(Cavity | Toothache)?

First, find P(Toothache) by marginalisation:

$$P(Toothache) = P(T|C)\cdot P(C) + P(T|\neg C)\cdot P(\neg C)$$ $$= 0.70 \times 0.10 + 0.10 \times 0.90 = 0.07 + 0.09 = 0.16$$

Then apply conditional probability:

$$P(Cavity | Toothache) = \frac{P(T|C)\cdot P(C)}{P(T)} = \frac{0.07}{0.16} \approx 0.4375$$

2. Bayes' Theorem

Bayes' Theorem

$$P(H|E) = \frac{P(E|H)\cdot P(H)}{P(E)}$$
  • \( P(H) \) — Prior: belief in hypothesis H before seeing evidence
  • \( P(E|H) \) — Likelihood: how probable is the evidence if H is true
  • \( P(H|E) \) — Posterior: updated belief after seeing evidence
  • \( P(E) \) — Normalising constant (sum over all hypotheses)

Intuition: COVID Test Example

Disease prevalence P(D) = 0.01. Test: P(+|D) = 0.95, P(+|¬D) = 0.05.

If you test positive, what's the chance you have the disease?

$$P(D|+) = \frac{0.95 \times 0.01}{0.95\times0.01 + 0.05\times0.99} = \frac{0.0095}{0.0095+0.0495} \approx 0.16$$

Despite a 95% accurate test, only ~16% chance of disease — because the disease is rare. This is why base rates matter.

🔑 Bayes' Theorem — Exam Form

$$P(H|E) = \frac{P(E|H)\cdot P(H)}{\sum_{h} P(E|H{=}h)\cdot P(H{=}h)}$$

The denominator is just the marginal \( P(E) \) expanded over all possible hypotheses. In exam problems with two states (e.g., disease/no-disease), expand to two terms.

3. Bayesian Networks — Structure

A Bayesian Network (BN) is a Directed Acyclic Graph (DAG) where:

  • Each node = a random variable
  • Each directed edge X → Y means "X directly influences Y" (X is a parent of Y)
  • Each node stores a Conditional Probability Table (CPT): \( P(X | Parents(X)) \)

Why Bayesian Networks?

A full joint distribution over n binary variables needs \( 2^n - 1 \) numbers. A BN with sparse connections needs far fewer — it exploits conditional independence.

Conditional independence: X is conditionally independent of its non-descendants given its parents. This lets us factorise the joint distribution:

$$P(X_1, X_2, \ldots, X_n) = \prod_{i=1}^{n} P(X_i \mid Parents(X_i))$$

Toothache / Cavity / Catch Network (from Aug 2 session)

Three variables: Cavity (C), Toothache (T), Catch (Ct) — a dentist's probe catches on the tooth.

Cavity (C) / \ ↓ ↓ Toothache (T) Catch (Ct) Interpretation: C → T : having a cavity causes toothache C → Ct: having a cavity causes the probe to catch T and Ct are conditionally independent given C

The joint distribution factorises as:

$$P(C, T, Ct) = P(C) \cdot P(T|C) \cdot P(Ct|C)$$

Exam Trap: Correlation ≠ Causation in BNs

Edges represent probabilistic influence (often causal), but are chosen to capture conditional independence structure. Toothache and Catch are correlated (both happen with cavities), but no edge connects them — because they are conditionally independent given Cavity. Always ask: "Given the parent(s), does this node still directly affect that one?"

Constructing a BN from a Scenario — Steps

  1. List all relevant random variables
  2. Order them from causes to effects (topological order)
  3. For each variable, identify its direct causes (parents): "Is this variable directly influenced by others, or only via some intermediate variable?"
  4. Draw edges from each parent to child
  5. Fill in the CPT for each node: one row per combination of parent values

CPT size rule: a node with k binary parents needs \( 2^k \) rows (one per parent combination), each row summing to 1.

🔑 CPT Size Formula

A binary node with k binary parents needs \( 2^k \) independent probability values (one per parent combo). The full BN over n binary nodes needs at most \( \sum_{i=1}^{n} 2^{|Parents(X_i)|} \) values — far less than \( 2^n \) for the full joint.

5. Bayesian Network Inference

Joint Probability Query

Use the factorisation: \( P(X_1,\ldots,X_n) = \prod_i P(X_i | Parents(X_i)) \)

Worked Example — Joint Probability

What is \( P(Cavity{=}T,\; Toothache{=}T,\; Catch{=}F) \)?

$$P(C,T,\neg Ct) = P(C)\cdot P(T|C)\cdot P(\neg Ct|C)$$ $$= 0.10 \times 0.70 \times 0.20 = \mathbf{0.014}$$

Conditional (Query | Evidence) Probability

To find \( P(Query \mid Evidence) \), use:

$$P(Q|E) = \frac{P(Q,E)}{P(E)}$$

\( P(E) \) is the marginal — sum \( P(Q,E) \) over all values of Q.

Worked Example — Conditional Probability from BN

Given Toothache = true, what is P(Cavity = true)?

Step 1: Find joint \( P(C{=}T, T{=}T) \) — marginalise over Catch:

$$P(C,T) = P(C)\cdot P(T|C)\cdot\underbrace{\sum_{ct} P(ct|C)}_{=1} = P(C)\cdot P(T|C)$$
CavityP(C)P(T=true|C)P(C, T=true)
true0.100.700.10 × 0.70 = 0.070
false0.900.100.90 × 0.10 = 0.090
P(T=true) = sum0.160

Step 2: Normalise:

$$P(C{=}T \mid T{=}T) = \frac{0.070}{0.160} \approx \mathbf{0.4375}$$

Exam Trap: Forgetting to Normalise

When computing conditional probability, the numerator P(Query, Evidence) is the joint. You must divide by P(Evidence) to get a valid probability. Leaving the answer as the raw joint (e.g., 0.070 instead of 0.4375) is a guaranteed marks loss. Always write out the normalisation step explicitly.

6. Markov Models — Temporal Reasoning

Bayesian Networks model static uncertainty. For time-varying worlds — tracking a robot's position, predicting weather, speech recognition — we need temporal models.

Markov Assumption

The first-order Markov assumption says the current state depends only on the immediately preceding state:

$$P(X_t \mid X_{t-1}, X_{t-2}, \ldots, X_0) = P(X_t \mid X_{t-1})$$

This collapses an exponentially large history into just one previous state — making inference tractable.

Transition Probability Matrix (TPM)

The TPM encodes all transition probabilities. Entry \( a_{ij} = P(X_t{=}j \mid X_{t-1}{=}i) \).

Example — Weather model (Sunny / Rainy):

From \ ToSunny (t)Rainy (t)
Sunny (t−1)0.700.30
Rainy (t−1)0.400.60

Key property: each row sums to 1 (you must go somewhere next step).

Using matrix notation, the state distribution at time t is:

$$\boldsymbol{\pi}_t = \boldsymbol{\pi}_{t-1} \cdot A$$

where \( \boldsymbol{\pi}_t \) is the row vector of state probabilities and A is the TPM.

Worked Trace — Multi-step Prediction

Initial: P(Sunny) = 0.8, P(Rainy) = 0.2. What is the distribution after 2 days?

DayP(Sunny)P(Rainy)Computation
00.8000.200Initial distribution
10.800×0.70 + 0.200×0.40 = 0.6400.800×0.30 + 0.200×0.60 = 0.360\( \boldsymbol{\pi}_0 \cdot A \)
20.640×0.70 + 0.360×0.40 = 0.5920.640×0.30 + 0.360×0.60 = 0.408\( \boldsymbol{\pi}_1 \cdot A \)

🔑 Markov Model Key Facts

  • First-order Markov: current state depends only on previous state
  • TPM rows always sum to 1
  • Stationary distribution: \( \boldsymbol{\pi} = \boldsymbol{\pi} \cdot A \) — long-run frequency regardless of starting state
  • Second-order Markov: \( P(X_t | X_{t-1}, X_{t-2}) \) — captured by expanding state space

7. Hidden Markov Models (HMM)

In a plain Markov model we observe the state directly. In an HMM the true state is hidden — we only see noisy observations.

HMM Structure

  • Hidden states: \( X_1, X_2, \ldots, X_T \) — follow the Markov property via the TPM
  • Observations: \( O_1, O_2, \ldots, O_T \) — each emitted from the current hidden state
  • Emission probability: \( P(O_t \mid X_t) \) — how likely each observation is from each state
  • Emission Probability Matrix (EPM): \( b_{j}(o) = P(O_t{=}o \mid X_t{=}j) \)

EPM rows (one per hidden state) sum to 1.

Weather / Pressure HMM (from 16 Aug session)

Hidden states: Weather ∈ {Sunny, Rainy}

Observations: Pressure ∈ {High, Low}

Initial: P(Sunny) = 0.8, P(Rainy) = 0.2

TPM A:

From \ ToSunnyRainy
Sunny0.700.30
Rainy0.400.60

EPM B (emission):

State \ ObsHigh pressureLow pressure
Sunny0.900.10
Rainy0.200.80

Intuition: Sunny days mostly have high pressure; rainy days mostly have low pressure. We observe pressure but not the weather directly.

HMM as a graphical model: X₁ ──→ X₂ ──→ X₃ ──→ ... (hidden states, Markov chain) | | | ↓ ↓ ↓ O₁ O₂ O₃ (observed) Joint: P(X₁..T, O₁..T) = P(X₁)·∏ P(Xₜ|Xₜ₋₁)·∏ P(Oₜ|Xₜ)

8. HMM Algorithms & Viterbi

Three Core Tasks

HMM Tasks

TaskQuestion answeredAlgorithm
FilteringWhat is the current hidden state given all observations so far? \( P(X_t | o_{1:t}) \)Forward algorithm (FPA)
SmoothingWhat was the hidden state at time k given all observations? \( P(X_k | o_{1:T}), \; k < T \)Forward–Backward algorithm
Most likely pathWhat is the single most probable state sequence? \( \arg\max P(x_{1:T} | o_{1:T}) \)Viterbi algorithm

Forward Propagation Algorithm (FPA) — Filtering

FPA Recurrence

Define \( \alpha_t(j) = P(o_1, o_2, \ldots, o_t, X_t{=}j) \) — joint probability of observations and being in state j at time t.

Initialisation (t = 1):

$$\alpha_1(j) = P(X_1{=}j) \cdot b_j(o_1)$$

Recurrence (t = 2, 3, …):

$$\alpha_t(j) = b_j(o_t) \cdot \sum_{i} \alpha_{t-1}(i) \cdot a_{ij}$$

Filtering result: \( P(X_t{=}j | o_{1:t}) = \dfrac{\alpha_t(j)}{\sum_k \alpha_t(k)} \)

Viterbi Algorithm — Most Likely State Sequence

Viterbi Recurrence

Define \( \delta_t(j) \) = probability of the most likely path ending in state j at time t:

Initialisation:

$$\delta_1(j) = P(X_1{=}j) \cdot b_j(o_1)$$

Recurrence:

$$\delta_t(j) = \max_{i}\,\bigl[\delta_{t-1}(i) \cdot a_{ij}\bigr] \cdot b_j(o_t)$$

Backtracking: store \( \psi_t(j) = \arg\max_i[\delta_{t-1}(i)\cdot a_{ij}] \) at every step. After reaching T, trace back from \( \arg\max_j \delta_T(j) \).

Viterbi Worked Trace — Weather/Pressure (2 steps)

Observation sequence: O₁ = High, O₂ = Low. States: S = Sunny, R = Rainy.

Exam Traps — HMM

  • Viterbi uses max, FPA uses sum: \( \delta_t(j) = \max_i[\cdots] \cdot b_j(o_t) \) vs \( \alpha_t(j) = \sum_i[\cdots] \cdot b_j(o_t) \). Mixing them is a common error.
  • EPM rows must sum to 1: \( \sum_o b_j(o) = 1 \) for each hidden state j.
  • TPM rows must sum to 1 (not columns).
  • Always show the backtrack: stating just the final δ values without tracing back earns no credit for the "most likely path" question.
  • Dynamic Bayesian Networks are excluded from EC3 (confirmed by Prof. PD on 23 Aug).

🔑 HMM Formula Summary

AlgorithmRecurrenceKey operator
FPA (Filtering)\( \alpha_t(j) = b_j(o_t)\cdot\sum_i \alpha_{t-1}(i)\cdot a_{ij} \)∑ (sum)
Viterbi (Best path)\( \delta_t(j) = b_j(o_t)\cdot\max_i[\delta_{t-1}(i)\cdot a_{ij}] \)max

Both initialise as: value₁(j) = P(X₁=j) · b_j(o₁).
Both are completed by backtracking from the best final state.

9. Practice Problems

✏️ Self-Check 1: BN Inference — P(Cavity = T, Toothache = F, Catch = T)

Solution

Using the Toothache network (§4):

$$P(C{=}T, T{=}F, Ct{=}T) = P(C)\cdot P(T{=}F|C)\cdot P(Ct{=}T|C)$$ $$= 0.10 \times 0.30 \times 0.80 = \mathbf{0.024}$$

If asked for P(Ct=T | C=T, T=F): this is just P(Ct=T|C=T) = 0.80 — Catch and Toothache are conditionally independent given Cavity, so T=F doesn't affect Ct.

✏️ Self-Check 3: Construct a BN for "Sprinkler / Rain → Wet Grass"

Solution

Variables: Cloudy (C), Sprinkler (S), Rain (R), WetGrass (W).

Cloudy (C) / \ ↓ ↓ Sprinkler Rain \ / ↓ ↓ WetGrass

Factorisation: \( P(C,S,R,W) = P(C)\cdot P(S|C)\cdot P(R|C)\cdot P(W|S,R) \)

CPTs needed: P(C) [1 value], P(S|C) [2 values], P(R|C) [2 values], P(W|S,R) [4 values] = 9 values total.

Full joint without BN would need \( 2^4 - 1 = 15 \) values. BN reduces storage by encoding conditional independence.
