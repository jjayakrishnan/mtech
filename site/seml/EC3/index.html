Exam Strategy

  • Patterns (S8) — Know Saga vs Blackboard vs Orchestration. Exam will likely give a scenario and ask which pattern to use.
  • Frameworks (S9) — Know ReAct loop steps (Thought → Action → Observation). Be able to compare LangChain vs CrewAI vs AutoGen in a table.
  • Drift (S11) — Distinguish data drift (\(P(X)\) change) from concept drift (\(P(Y|X)\) change). Know PSI thresholds (0.1 / 0.2).
  • Docker (S12) — Dockerfile instruction order matters for caching. Know Image vs Container distinction precisely.
  • MLFlow (S13) — Know 4 components. Know registry stages (None → Staging → Production → Archived). Know 3 retraining triggers.
  • AgentOps (S14) — Know the 3 ops levels (MLOps / LLMOps / AgentOps). Know RAGAS's 4 metrics. Know when HITL is required.
